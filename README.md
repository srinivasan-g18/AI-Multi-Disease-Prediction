# 🩺 AI-Powered Multi-Disease Prediction System

An AI-powered healthcare application developed using Machine Learning and Streamlit for predicting the risk of multiple diseases.

## 🚀 Live Demo

[Open Srini Health AI](https://ganesansupramani1999-blip-srini-health-assista-srini-app-8b56vp.streamlit.app/)

## 🩺 Diseases Predicted

- Kidney Disease
- Hypertension
- Stroke
- Cancer
- Liver Disease
- Diabetes
- Heart Disease

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- Scikit-learn
- Streamlit
- Plotly
- ReportLab

## ⚙️ Methodology

Data Collection  
↓  
Data Preprocessing  
↓  
Model Training  
↓  
Model Evaluation  
↓  
Model Saving  
↓  
Streamlit Application  
↓  
Disease Risk Prediction

## 📊 Model Evaluation

The system evaluates disease-specific models using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC Curve
